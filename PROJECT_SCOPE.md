# ResumePilot AI — Project Scope

## Problem

Recruiters often need to compare many resumes against job descriptions.
Traditional resume screening can produce an overall score without clearly
showing why a candidate matches or does not match a requirement.

## Solution

ResumePilot AI uses an AI-assisted, evidence-based workflow to break a job
description into requirements, find supporting evidence in the candidate's
resume, verify each requirement, and present the results for human review.

## Target Users

- Recruiters
- Hiring managers
- Talent acquisition teams

## Core MVP

1. Resume upload
2. Job description input
3. Requirement extraction
4. Evidence extraction
5. Requirement matching
6. Evidence verification
7. Human review
8. Evaluation/report output

## Main Value

Instead of providing only a score, ResumePilot AI shows the evidence behind
each evaluation so that a human can review the result.
